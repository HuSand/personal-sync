Privacy policy

Last updated: 9 October 2026

Who uses this app

Personal Sync is a private tool used only by its owner. It is not offered to other people.

What Google data it accesses

  • Gmail, read-only: bank transaction notification emails in the owner's own mailbox, used to record income and spending.
  • Google Drive, read-only: health export files (CSV) that the owner stores in their own Drive.

The app never sends, deletes or changes emails or files.

How the data is used and stored

Data is processed and stored only on the owner's personal computer, for the owner's own budgeting and health tracking. It is not sold, shared with third parties, used for advertising, or used to train AI models.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time from the Google Account's security settings under "Third-party apps with account access". Stored data can be deleted by removing the app's local database.

Contact

Questions can be raised through the issues page of this site's GitHub repository.
